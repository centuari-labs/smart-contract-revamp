## Full Security Audit — 2026-03-23

**Scope**: All contracts in `src/core/` and `src/core/centuari/` and `src/core/pcbt/` (26 contracts reviewed)

**Branch**: feat/centuari-full-implementation

### CRITICAL (5)
1. **LiquidationEngine.sol:116-127** — liquidate() reduces borrower collateral/debt but never transfers debt FROM liquidator or credits collateral TO liquidator. Collateral is destroyed.
2. **RiskModule.sol:194-198** — No `answer > 0` check on Chainlink price. Negative int256 wraps to ~2^255 uint256. Corrupts all HF calculations.
3. **CentuariEndpoint.sol:81-92** — Batch digest hashes array lengths + pre-computed batchHash, NOT actual operations. Signer signs metadata, not content.
4. **CentuariEndpoint.sol:169** — CBT tolerance check underflows when expectedCBT could be 0. `expectedCBT - CBT_TOLERANCE` wraps.
5. **CentuariBondERC20.sol:96-109** — redeem() burns CBT but does NOT transfer underlying tokens. Total loss at maturity.

### HIGH (9)
1. BalanceLedger.sol:268 — withdraw() no HF check
2. CentuariEndpoint.sol:221-228 — Rollover CBT mint not validated
3. AssetBehaviorRegistry.sol:52 — addAsset() no 48h timelock (Invariant #7 violated)
4. YieldRouter.sol:213-220 — verifyReserveRatio() always returns true (no-op)
5. CentuariRateOracle — updateSigner() no timelock
6. CentuariEndpoint.sol:181-190 — Low-level .call() for CBT minting
7. LiquidationEngine.sol:112 — Stale usdValueCached in seizure computation
8. LiquidationEngine.sol:85 — positionId collision (borrower+debtAsset only)
9. CentuariRouter — ERC-4626 stubs deployed as functional interface

### Recurring Patterns
- Missing oracle `answer > 0` validation
- Inconsistent timelock enforcement across admin functions
- Stub functions deployed as if functional
- Low-level .call() where typed interfaces should be used
- Missing transfer/payment in critical financial functions

**Why:** Pre-audit review before mainnet. Centuari handles real user funds in fixed-rate credit markets.

**How to apply:** All CRITICALs must be fixed before any deployment. All HIGHs before testnet. Professional audit required after fixes.
