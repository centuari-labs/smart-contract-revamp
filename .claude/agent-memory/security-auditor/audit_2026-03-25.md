## Audit Report: 2026-03-25 (Round 5 - Definitive Final)

**Scope**: 12 hub core contracts + 8 storage contracts
**Result**: 2 CRITICAL, 3 HIGH, 5 MEDIUM, 4 LOW, 3 INFO

### CRITICAL

1. **LiquidationEngine.liquidate() HF check uses stale cached values (LiquidationEngine.sol:80 + RiskModule.sol:240)** — HF gating reads usdValueCached while seizure uses fresh oracle. Healthy positions can be wrongfully liquidated when keeper refresh lags. Recurring pattern #5.

2. **LiquidationEngine.liquidate() permissionless path has no token transfers (LiquidationEngine.sol:69-140)** — Accounting changes (reduceCollateral, reduceUserDebt) without any ERC20 movement. Debt reduced without payment. Recurring pattern #2.

### HIGH

1. **5 contracts have instant admin setters without timelock (RiskModule, LiquidationEngine, CollateralRegistry, YieldRouter, BalanceLedger)** — CentuariEndpoint was fixed (NH-04) but fix not propagated. Recurring pattern #4.

2. **Debt double-counting per collateral asset (CentuariEndpoint.sol:216-232)** — Full debt recorded against EACH collateral asset, inflating debt ceiling counters by N collateral types.

3. **RiskModule.setAuthorizedCaller instant setter (RiskModule.sol:219)** — Allows instant granting of debt manipulation ability, enabling instant position assassination.

### KEY INVARIANT FAILURES

- Invariant #20 (admin timelocks): FAIL across 5 contracts
- Invariant #23 (interest accrued before HF check): FAIL in LiquidationEngine — no interest accrual before HF check

### Patterns Recurring From Prior Audits

- Pattern #5 (stale cached values): 3rd occurrence
- Pattern #2 (accounting without token transfer): 2nd occurrence
- Pattern #4 (missing timelocks): 2nd occurrence after partial fix
